# learn

Short animated explainers about working with AI. Live at https://learn.brajk.com.

## Lessons

**[Effort](https://learn.brajk.com/effort/)**: what the effort setting on an AI model actually changes. The same agent does the same job at five effort levels, from low to max. Higher effort means more looking and more checking, and on easy jobs it adds things nobody asked for. Switch between Claude Fable 5.1, Opus 5.5 and Sonnet 5.5 to see that a more capable model needs less effort to get the same job right.
